# DeepSeek Code Manager

> افزونه‌ای سبک برای Chrome که کار با بلوک‌های کد در **DeepSeek Chat** را ساده می‌کند و امکان اعمال بسته‌های تغییرات ساختاریافته (Code Change Package) را مستقیم روی پوشه پروژه فراهم می‌سازد.

---

## ✨ ویژگی‌ها

- **جمع‌کردن / بازکردن کدها** — هر بلوک کد یک دکمهٔ جمع/باز دارد؛ همه با یک کلیک هم قابل کنترل‌اند.
- **شناسایی کدهای صفحه** — پاپ‌آپ فهرست بلوک‌ها را با زبان و مسیر احتمالی فایل نشان می‌دهد.
- **ساخت فایل در پوشه پروژه** — با File System Access API، کدها مستقیم در ساختار درست نوشته می‌شوند.
- **اعمال Code Change Package (CCP)** — سه نوع تغییر:
  - `create` — ساخت فایل جدید
  - `patch` — اعمال Git Unified Diff روی فایل موجود
  - `replace` — جایگزینی کامل فایل
- **تشخیص با تیتر `diff`** — کافی است بالای JSON یک تیتر `### diff` باشد (همچنین `code-change-package` و `ccp`).
- **پیست دستی JSON** — اگر تشخیص خودکار کار نکرد، JSON را در پاپ‌آپ پیست کنید.
- **مسیرهای امن** — فقط مسیر نسبی؛ `..`، مسیر مطلق و درایو ویندوز رد می‌شود.
- **بدون ارسال داده به بیرون** — همه پردازش‌ها محلی‌اند.

---

## 📦 نصب

1. ریپازیتوری را کلون یا دانلود کنید.
2. در Chrome به `chrome://extensions` بروید.
3. **Developer mode** را فعال کنید.
4. **Load unpacked** را بزنید و پوشه پروژه را انتخاب کنید.
5. آیکون افزونه در نوار ابزار ظاهر می‌شود.

---

## 🚀 استفاده

### ۱. انتخاب پوشه پروژه
از پاپ‌آپ روی **انتخاب پوشه پروژه** بزنید و یک پوشه انتخاب کنید. دسترسی پس از انتخاب ذخیره می‌شود.

### ۲. جمع‌کردن کدها
- **شناسایی کدهای صفحه** — فهرست بلوک‌ها را می‌آورد.
- **جمع‌کردن همه / بازکردن همه** — برای مدیریت سریع کدهای طولانی.

### ۳. ساخت فایل‌ها
- بلوک‌های دارای مسیر را تیک بزنید.
- گزینهٔ **جایگزینی فایل‌های موجود** را در صورت نیاز فعال کنید.
- روی **ساخت فایل‌های انتخاب‌شده در پروژه** بزنید.

### ۴. اعمال Code Change Package
1. در پاسخ مدل، بالای بلوک JSON یک تیتر بگذارید:

   ```markdown
   ### diff
   ```json
   { "format": "code-change-package", ... }
   ```
   ```

2. در پاپ‌آپ روی **بازخوانی بسته از صفحه** بزنید.
3. فایل‌ها را بررسی و تأیید کنید.
4. روی **اعمال بسته تغییرات** بزنید.

> اگر تشخیص خودکار انجام نشد، بخش **پیست دستی JSON** را باز کنید، متن را پیست و روی **تحلیل JSON پیست‌شده** بزنید.

## 🧩 ساختار Code Change Package

```json
{
  "format": "code-change-package",
  "version": 1,
  "project": { "name": "my-project" },
  "summary": "توضیح تغییرات",
  "files": [
    {
      "path": "src/example.js",
      "action": "create",
      "content": "// کد کامل فایل جدید"
    },
    {
      "path": "src/app.js",
      "action": "patch",
      "patch": "--- a/src/app.js\n+++ b/src/app.js\n@@ -1,3 +1,4 @@\n ..."
    },
    {
      "path": "src/config.js",
      "action": "replace",
      "content": "// محتوای کامل جایگزین"
    }
  ],
  "commands": ["npm install", "npm run build"]
}
```

### قواعد
- `format` دقیقاً `code-change-package` و `version` برابر `1` باشد.
- `action` فقط یکی از `create` / `patch` / `replace`.
- `path` نسبی و بدون `/` ابتدایی؛ بدون `..`.
- برای `patch` از **Git Unified Diff** استاندارد (`--- a/...`، `+++ b/...`، `@@ -l,c +l,c @@`) استفاده کنید.
- رشته‌ها باید JSON معتبر و Escape‌شده باشند.

## 🔐 مجوزها

| مجوز | دلیل |
|------|------|
| `activeTab` | دسترسی موقت به تب فعال |
| `scripting` | تزریق اسکریپت در صفحه DeepSeek |
| `storage` | نگه‌داری تنظیمات |
| `tabs` | شناسایی تب فعال برای ارسال پیام |

دسترسی میزبان محدود است به:
- `https://chat.deepseek.com/*`
- `https://*.deepseek.com/*`

هیچ داده‌ای به سرور خارجی ارسال نمی‌شود.
